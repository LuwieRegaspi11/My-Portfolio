# Luwie Regaspi — Portfolio

Static site (HTML/CSS/JS only — no build step needed).

## Deploy to GitHub Pages
1. Push this whole folder (index.html + style.css + assets/) to your repo.
2. On GitHub: Settings → Pages → set source to your branch/root.
3. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

## Contact form
The contact form opens the visitor's email app with the message pre-filled (via a `mailto:` link) — no backend needed, so it works as-is on GitHub Pages. If you'd rather collect submissions directly on the page instead of relying on the visitor's email client, you can swap it for a free static-form service like Formspree or EmailJS.
